# Projeto Quântica ⚛️

Visualização de orbitais atômicos em Python.

## Sobre o projeto

Por meio de uma invenção e pensamentos sobre Fisica Quântica e Python, desenvolvi uma órbita atômica onde se pode ver a beleza da matemática e física criando vida.

O projeto calcula a parte angular dos orbitais atômicos usando polinômios de Legendre associados e gera gráficos dos seus formatos (s, p, d, f).

## Conceitos usados

- Polinômios de Legendre associados
- Harmônicos esféricos
- Números quânticos: `l` (tipo do orbital: 1 = p, 2 = d, 3 = f...) e `m` (orientação)

## Estrutura

| Arquivo | Descrição |
|---|---|
| `quantica.py` | Cálculo dos polinômios de Legendre e visualização dos orbitais |
| `quantica_modelo.py` | Modelo teste |
| `flor.py` | Nome e primeiro resultado |

## Tecnologias

- Python 3
- NumPy
- Matplotlib

## Como rodar

```bash
git clone https://github.com/isadoradanni62-pixel/Projeto-quantica.git
cd Projeto-quantica
pip install numpy matplotlib
python quantica.py
```
